# SwashBuckle Backend API

Express.js backend for SwashStore eCommerce application.

## Port
Runs on: http://localhost:5095\n
## Endpoints
- GET /api/product/OnSale - Returns on-sale products (priced in INR ₹)
- GET /api/product/Featured - Returns featured products (priced in INR ₹)
- POST /api/user/register - Register user & set cookie
- POST /api/user/login - Login user & set cookie
- GET /api/user/fetch - Fetch current user
